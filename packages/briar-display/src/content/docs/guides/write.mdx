# How to Write Articles

Learn how to create and publish articles in the Briar Wiki.

## Getting Started

1. Create an account or log in
2. Navigate to the wiki section
3. Click "Create New Article"

## Formatting

Use Markdown syntax to format your articles:

```markdown
# Heading 1

## Heading 2

**Bold text**
_Italic text_

- Bullet point
- Another point

1. Numbered item
2. Second item

[Link text](https://example.com)
```

## Tips

- Write clear, concise titles
- Add a summary for better discoverability
- Use proper heading hierarchy
- Include code examples when relevant
- Save as draft before publishing

## Publishing

Once you're satisfied with your article:

1. Click "Save & Publish"
2. Your article will be visible to all users
3. You can edit or delete published articles anytime
